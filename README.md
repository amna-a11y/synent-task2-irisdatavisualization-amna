# Task 2 – Iris Dataset Data Visualization

## Problem Statement

The objective of this task is to visualize patterns and relationships in the Iris dataset using different graphical techniques. Data visualization helps in understanding trends, distributions, and comparisons between features in a simple and meaningful way.

---

## Dataset Details

* Dataset Name: Iris Dataset
* Source: Built-in dataset from Scikit-learn
* Format: Structured dataset

### Species

* Setosa
* Versicolor
* Virginica

### Features

* Sepal length
* Sepal width
* Petal length
* Petal width
* Species

---

## Approach

### 1. Data Loading

* Loaded the Iris dataset using Scikit-learn
* Converted the dataset into a Pandas DataFrame for easier analysis and visualization

### 2. Data Visualization Techniques

#### Bar Chart

* Visualized the count of each species
* Helped compare category distribution

#### Histogram

* Displayed the distribution of sepal length values
* Showed frequency and spread of the feature

#### Scatter Plot

* Compared sepal length and petal length
* Helped identify relationships between features and species separation

---

## Tools and Libraries Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

---

## Code Overview

### Main Steps

* Load Iris dataset
* Create DataFrame using Pandas
* Map target labels to species names
* Generate:

  * Bar chart
  * Histogram
  * Scatter plot

---

## Results

### Bar Chart

* All three species are equally distributed in the dataset

### Histogram

* Sepal length values follow a clear distribution pattern

### Scatter Plot

* Setosa species is clearly separated from others
* Versicolor and Virginica show partial overlap

---

## Key Insights

* Data visualization makes pattern recognition easier
* Scatter plots help identify feature relationships
* Histograms are useful for understanding data distribution
* Iris dataset shows clear class separation for some species
